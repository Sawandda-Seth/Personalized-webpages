# Personalized Webpage

## Project Overview

This project is an interactive personalized webpage built using **HTML**, **CSS**and **JavaScript**. The application allows users to enter their name and age, stores the information using the browser's **localStorage** and displays personalized content based on each user's input.

The project demonstrates fundamental JavaScript concepts including variables, functions, conditional statements, loops, DOM manipulation, and local storage.

---

## Features

### 1. User Input Form

* Collects the user's name and age.
* Validates user input through HTML form controls.
* Saves user information in localStorage.

### 2. Personalized Greeting

* Retrieves the user's name from localStorage.
* Displays a customized welcome message using JavaScript template literals.

### 3. Adult Content Access Check

* Uses an `conditional statements to determine whether the user is 18 years or older.
* Displays an appropriate message based on the user's age(includes an adults section).

### 4. Age in Months Calculator

* Implements a JavaScript function to calculate the user's age in months.
* Displays the calculated result.

### 5. Motivational Quotes

* Uses a `for` loop to display a motivational quote five times.

### 6. Responsive Design

* Styled using CSS.
* Mobile-friendly and responsive layout.
* Modern user interface with clean visuals and intuitive design.
